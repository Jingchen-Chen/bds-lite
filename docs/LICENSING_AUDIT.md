## Public release rule

No public release may contain a restricted file or a commit that ever contained one. The local branch `revision/peerj-major` fails this rule, because commits before `ee1d5ac` contain the removed images; it must not be pushed. Before any release, the authors must create the release from history that never contained them (for example a fresh branch or repository built from the current tree), and the release ref must pass

    python analysis/revision/check_release_clean.py <release-ref>

which scans every blob reachable from the ref, by content hash against `revision/restricted_local/` and by path. On 2026-11-07 it reported `HEAD: FAIL` for this branch (history) while the current tree contains no restricted image. Creating such a history is a rewrite that needs the authors' authorization and was not done.
